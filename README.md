# Пауза — контроль курения

Браузерное приложение, которое помогает увеличить интервал между сигаретами.
В центре — пачка **EMBER NOIR**, которая постепенно открывается, и сигарета, выходящая из неё
в момент «можно». Сигарету можно покрутить пальцем; за 5 минут она тлеет, пепел сползает вниз,
дым поднимается вверх, а затем окурок улетает и начинается новый интервал.
Есть статистика, еженедельный опрос и экспорт CSV. Интерфейс рассчитан на телефон:
нижняя навигация, крупные округлые стеклянные кнопки, опрос в виде bottom-sheet
и безопасные зоны iPhone. Лишние подписи, линии и эффекты убраны — осталось только нужное.

Приложение **статическое**: ему не нужен сервер. Данные хранятся только в браузере (localStorage),
аккаунт и облако не нужны. После первого открытия работает и без сети (Service Worker кэширует файлы).
Открыть можно с любого телефона в любом интернете — достаточно ссылки на сайт.

## Где открыть

Постоянная ссылка: https://andreutatarchyk2016-crypto.github.io/pause-stop-smoke/
Она открывается в любом браузере, компьютер для работы сайта не нужен.

Для локальной разработки:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd "stop-smoke"
npm install
npm run dev
```

Откройте http://localhost:5174. Vite слушает и IP локальной сети (`Network:` в выводе),
поэтому сайт можно открыть с телефона по адресу вида `http://192.168.0.156:5174`.

## Публикация

Сайт выложен на **GitHub Pages**: https://andreutatarchyk2016-crypto.github.io/pause-stop-smoke/
Ссылка постоянная, HTTPS, открывается с любого телефона без вашего компьютера.

Деплой настроен через `.github/workflows/deploy.yml`: после `git push` в `main` GitHub Actions
собирает проект с `VITE_BASE=/pause-stop-smoke/` и публикует `dist/`.
Локально такую сборку можно проверить командой `VITE_BASE=/pause-stop-smoke/ npm run build`.

Для Vercel в репозитории есть `vercel.json` (корневой путь без `VITE_BASE`): достаточно импортировать
репозиторий в Vercel с preset `Vite` — сборка и раздача `dist/` настроены.

Папка `server/` и файлы `lib/push.ts`, `lib/schedule.ts` остались от версии с Web Push
и в статической сборке не используются. Уведомления можно вернуть позже, подключив
любой push-сервис; данные о курении всё равно останутся в браузере.

## Как пользоваться

1. **Настройки** → интервал между сигаретами (по умолчанию 60 мин) и цель на день.
2. Пока идёт интервал, пачка постепенно открывается. Когда пройдёт время, из неё выходит сигарета —
   её можно покрутить пальцем.
3. Нажмите **«Я покурил(а)»**, чтобы записать сигарету: отсчёт начнётся заново. Можно нажать
   **«Не курил — пропустить»** или ничего не делать: через 5 минут окурок улетит,
   а пропущенное окно **не попадёт в статистику**.
   Если не удержались во время ожидания, нажмите **«Записать срыв»** — это честно отразится в графике.
4. **Статистика** — серия дней по графику, лучший интервал, график за 7 дней, экспорт CSV.
   Кнопка **«Добавить»** позволяет внести сигареты вручную: просто количество (1–60) и статус
   «по графику» или «срыв» — дата и время вводить не нужно. Число сразу попадает во все счётчики
   и в график; ошибочную запись можно удалить кнопкой корзины в журнале.
5. **Недели** — итоги текущей недели и история опросов. Опрос за прошедшую неделю открывается сам
   при первом открытии приложения в понедельник.

## Структура

```
src/
  App.tsx                  состояние приложения, навигация, побочные эффекты
  components/
    CigarettePack.tsx       кольцо, 3D-пачка и SVG-сигарета: пепел, уголь, дым, вращение пальцем
    BackgroundDecor.tsx     живой фон: дым, орбиты, текстура, стекло, рябь
    TimerView.tsx           главный экран
    StatsView.tsx           метрики, график, журнал, экспорт CSV
    ManualEntrySheet.tsx    ручное добавление числа сигарет (bottom-sheet)
    WeeksView.tsx           недельные итоги
    WeeklyReviewModal.tsx   опрос
    SettingsView.tsx        настройки
  lib/
    storage.ts              localStorage
    time.ts                 даты, недели, форматирование
    stats.ts                серии, интервалы, данные графика
    phase.ts                цвет фона по прогрессу
public/
  sw.js                     офлайн-кэш
  icon.svg                  иконка
vercel.json                 настройки статического деплоя
```

Внешний вид сигареты и пачки (косой пепельный срез, уголька на кромке, кремовая этикетка,
золотая фольга, целлофан, палитра) сделан по образцу `~/grafik-pvz/design/quit-smoking/cigarette.svg`
и `pack.svg`.

Это приложение для самоконтроля, а не медицинский инструмент. Если нужна поддержка — в России работает
бесплатная телефонная линия помощи 8-800-200-01-22 (Всероссийская служба помощи по вопросам курения).
